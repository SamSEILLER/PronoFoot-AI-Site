# Club crests / attribution

The site serves the club crests in this directory locally from `assets/crests/`; match rows prefer these local files over provider-supplied image URLs to avoid incorrect club-to-logo associations.

The SVG files were copied from the public repository [JoseArroyave/football-logos](https://github.com/JoseArroyave/football-logos), paths in its `logos/` directory. That repository describes its files as football team logos sourced from public APIs and organized by country. Club names and marks remain the property of their respective clubs/rightsholders. These files are included for club identification in a football fixtures interface. Review the upstream repository's current license/terms before redistributing this project commercially.

Files added in this batch are keyed by normalized club slug (for example, `annecy.svg`, `kvmechelen.svg`, `standardliege.svg`). If a crest is missing or incorrect, update the local asset and mapping together.
